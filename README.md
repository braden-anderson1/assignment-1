# Assignment 1 — Amazon Gift Card Review Sentiment Classifier

Sentiment classification of Amazon gift-card reviews from the
[Amazon Reviews 2023 dataset](https://mcauleylab.ucsd.edu/public_datasets/data/amazon_2023/)
(Gift Cards category), using **only** the review `title` and `text`.

## Label scheme

| Rating | Class      |
|--------|------------|
| 4–5    | POSITIVE   |
| 3      | NEUTRAL    |
| 1–2    | NEGATIVE   |

The star rating is used **only** to build ground-truth labels — it is never sent
to the classifier as an input.

## Sampling

A balanced, stratified random draw is pulled from the **whole** file (~50 per
class, fixed seed 42), not the first N rows in order, so the rare NEUTRAL class
is represented fairly and the same sample reproduces on every run.

## Two methods (compared)

1. **LLM prompt-based** — `classifier.py` calls a reasoning LLM
   (`cyankiwi/Qwen3.6-35B-A3B-AWQ-4bit`) that must answer exactly
   `POSITIVE` / `NEUTRAL` / `NEGATIVE` from the title+text, weighting the body
   text over the title when they conflict.
2. **NRC lexicon (no model calls)** — `nrc_classifier.py` scores each review's
   words against the [NRC Emotion Lexicon v0.92](https://github.com/Franck-Dernoncourt/NRC_Emotion_Lexicon)
   (Mohammad & Turney, 2013): sentiment = sign of summed positive-vs-negative
   flags; primary emotion = the most-hit of anger, anticipation, disgust, fear,
   joy, sadness, surprise, trust.

## Results (150 balanced reviews)

| Metric | LLM | NRC |
|--------|-----|-----|
| Accuracy | 74.0% | 46.4% (decided) |
| Macro-F1 | 72.1% | — |

The LLM is substantially better at sentiment; the main weakness for both is the
NEUTRAL class (3-star reviews are genuinely mixed). NRC's primary-emotion read is
dominated by *anticipation*, which tracks the gift/order vocabulary rather than
sentiment.

## Dashboard

`dashboard.html` is a single self-contained, offline page comparing the two
methods: per-class correct-vs-predicted bars, LLM confusion matrix, primary
emotion, and an explorable per-review table (filter + search + live count).
`dashboard_full.html` is the verbose variant. Both are generated by
`generate_dashboard.py` / `generate_dashboard_full.py` from
`predictions_nrc.jsonl`.

## Usage

```bash
# 1. Download the dataset (not committed; ~60 MB)
curl -L -O https://mcauleylab.ucsd.edu/public_datasets/data/amazon_2023/raw/review_categories/Gift_Cards.jsonl.gz
gunzip Gift_Cards.jsonl.gz

# 2. Run the LLM classifier (balanced 50/class, seed 42)
python3 classifier.py --n 50 --seed 42 --fresh

# 3. Score with the NRC lexicon and compare
python3 nrc_classifier.py

# 4. Regenerate the dashboard
python3 generate_dashboard.py
```

## Files

- `classifier.py` — LLM classifier + balanced sampling + multiclass metrics
- `nrc_classifier.py` — NRC lexicon scorer + comparison
- `NRC_emotion_lexicon.txt` — downloaded NRC EmoLex v0.92
- `predictions_42_50.jsonl` — LLM predictions (150)
- `predictions_nrc.jsonl` — enriched with NRC sentiment + primary emotion
- `generate_dashboard.py` / `generate_dashboard_full.py` — dashboard builders
- `dashboard.html` / `dashboard_full.html` — self-contained dashboards
